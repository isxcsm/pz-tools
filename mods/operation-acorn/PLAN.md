# 이야기 작업 계획

SCENES.md, LORE.md, CANON.md가 정한 이야기와 연출을 게임에 넣는 순서다. 단계가 끝나면 여기에 표시한다. 정책을 정해야 하는 일이 나오면 멈추고 묻는다. 그 밖의 세부는 작업하며 정한다.

| 단계 | 내용 | 확인 | 상태 |
| --- | --- | --- | --- |
| 0. 준비 | 옛 코드 대조표(아래), 기술 확인, 교신 탭 목업 | 목업 확인. 게임 확인은 1단계 확인에 몰아서 | 끝 |
| 1. 뼈대 | 장면 순서 규칙, 교신 탭 재생기와 기록, 임시 시설 장소 고르기, 이야기 무대 깔기, 제목 카드 | 합성 테스트 | 끝 (무대 부품의 실제 동작은 2단계 게임 확인에서) |
| 2. 1단계 끝까지 | S0, S1, S1F, 임시 경찰 초소 무대, 1단계 문서. 옛 고정 장소와 무전 사본 정리 | 게임 확인: 감정, 줄 시간, 대본 다듬기 | 코드 끝. 게임 확인 대부분 끝 (무대 부품, 죽은 척 깨우기, 무전기 잡음). 교신 탭 확인은 3단계 끝 게임 확인에 몰아서 |

## 0단계: 기술 확인

| 무엇 | 쓰는 곳 | 상태 |
| --- | --- | --- |
| 확장 API 텍스트 효과를 단말 창 안에 그리기 | 교신 탭 | 쓰지 않는다. API 텍스트는 화면 좌표에 UI 맨 위로 그려져 창이 움직이거나 겹치면 떠 버린다 (`Texts.java`). 교신 탭은 단말 폴더처럼 UI 키트의 타이핑(`PZUIKit.Typing`)으로 창 안에 그리고, 신호 효과(깜박이며 들어옴)는 탭이 직접 그린다. API 작업은 없다 |
| 죽은 척하는 좀비를 트리거로 깨우기 | 1, 2, 5단계 | 확인함 (게임): 죽은 척하는 시체는 `IsoDeadBody.isFakeDead()`이고 `reanimateNow()`로 일으킨다. 무대가 그 칸을 알고 있어 시체를 바로 찾는다. 1단계 무대에서 봉투를 집자 일어났다 |
| 위치에서 반복해 울리다 끄면 멎는 소리 | 1, 2, 4, 7단계 | 확인함 (jar): 켜 둔 무전기와 라디오는 받을 신호가 없으면 `RadioStatic`을 반복한다 (`DeviceData`). 플레이어가 끄면 멎는다. 바닐라 동작 그대로라 따로 만들 것이 없다. 확인함 (게임): `IsoRadio.new`로 놓은 무전기는 기기 데이터를 갖고, 켜 두면 잡음을 내고 끄면 멎는다. 무대는 켠 채로 놓는다 (`on`). 4단계 통신 천막의 '한 번 내는 호출'은 원에 들어설 때 무전기 자리에서 `RadioTalk`를 6초 낸다 (`call`, 에미터 소리라 좀비를 끌지 않는다) |
| 장면 중 게임 소리 낮추기 | 교신 탭 장면 | 함수 확인함 (jar): `SoundManager.setSoundVolume`, `setAmbientVolume`. 탭 장면은 게임을 멈추므로 월드 소리가 이미 멎을 수 있다. 무전 잡음은 `playUISound`로 깐다. 실제로 멈춤 중에 무엇이 들리는지는 게임 확인 |
| 플레이어에게만 들리고 좀비를 끌지 않는 소리 | 대기 알림 | 원리 확인함: 좀비는 `WorldSoundManager`에 더한 소리만 듣는다. 오브젝트 에미터로 소리만 내고 월드 소리를 더하지 않으면 좀비를 끌지 않는다. 게임 확인 |

## 3단계 메모

- 무대는 이야기별로 고른다 (`StageData.<이야기>`, 택 1은 `<이야기>_<선택>`, 이관 뒤 재방문은 원래 이야기의 것). 빈터 무대는 `ground`.
- 새 부품: 빈터 배치(`ground`, 가운데에서 `dx`, `dy`), 마당(`yard`), 뒷문(`back`), 바깥에서 판자 막기(`board`)와 대기 중 판자 떨어짐(`drop`), 출입문 잠금(`lockout`), 창 열기(`window`), 발전기(`generator`), 모래주머니 줄(`line`), 이름이나 2층으로 방 고르기(`names`, `up`), 대기에 걸쳐 차례로 깨우기(`during`), 헬기 때 시차 깨우기(`wake = "heli"`, `stagger`). 놓는 가구에는 빈 용기를 만든다 (뒤진 것으로 둠).
- S4 뒤 S4B 전까지(`Comms.silent`) 헬기 호출 알림에 "(자동)"이 붙는다.
- 바꿔치기: 시료함을 넣을 때와 대기가 끝날 때 혼잣말. 대기가 끝나면 접수처가 플레이어 눈 밖일 때 기록철이 놓인다 (`ready` 단계, `Game.dropSeen`).
- SCENES와 다르게 둔 것: B42 바닐라에 쌍안경이 없어 3단계 (가) 무대에서 뺐다. 4단계 군용 바리케이드(`fencing_01_96~103`)는 방향을 알 수 없어 모래주머니로만 두르고, 표지는 모래주머니 줄 끝에 둔다. 통신 무전기의 호출은 원에 처음 들어설 때 한 번 난다 (`call`, Stage.event "enter"). 발전기를 돌리면 냉장함이 늦게 데워지는 것은 뺐다. 냉장함 온도는 처음 손에 든 때부터 오르게 해 두어(현장까지 가는 시간을 벌하지 않게), 냉장함이 발전기 옆에 있는 동안에는 데워질 것이 없기 때문이다. 발전기는 연료가 바닥난 소품으로 남는다.
- 3단계 게임 확인에서 고친 것: 가구 치우기(세트가 가는 방만), 장소 기준(생존자 거점·이벤트 집·상점 빼기, 도로 8~40칸 숲), 빈터 둘레를 들쭉날쭉하게 나무와 덤불만 치우기, 모드 차량 존 대응, 확장 API 제목 높이 0.16, 교신 줄 시간(언어별 읽기 속도), Kahlua 문자열 버그, 대사 말투(해요체, 반말은 강조, 끝맺은 문장).
