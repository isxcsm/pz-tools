# 연출 대본

이 문서는 이야기의 장면을 정한다. 교신 장면의 대본과 화면, 이야기 임무 현장의 무대, 그리고 그것을 만드는 데 필요한 월드 연출 부품이다. 주제, 감정선, 인물, 단서는 LORE.md가 정하고 이 문서는 그것을 화면에 옮긴다. 대본의 채집점 번호는 0347이다. 실제로는 세이브마다 다르다.

---

## 1. 원칙

- 감정이 큰 순간에만 연출한다. 단계마다 교신 장면 한두 개와 현장 하나다. 그 사이 수십 일은 생존 플레이로 남는다.
- 교신은 일정이 아니라 사건에 붙는다. 매일 오는 교신, 알람, 정해진 시각은 없다. 0730 같은 시각은 교신 기록 머리에 찍는 표기일 뿐이다.
- 대사 선택지는 없다. 주인공의 대사는 고정 대본이다. 3단계에서 두 집 가운데 하나를 고르는 것은 임무를 고르는 놀이의 선택이라 이 규칙과 다르다.
- 장면 하나는 12줄을 넘지 않는다. 건너뛸 수 있고, 건너뛰어도 교신 탭에 기록이 남아 다시 볼 수 있다.
- **2반과의 교신은 단말에서만 한다.** 단말 창의 교신 탭에서 재생되고 그 탭에 기록이 남는다 (2장). 현장에서 주인공은 혼잣말만 한다. 현장 일은 그 임무 물건이 든 상자가 회수된 뒤 단말에서 이야기한다. 예외는 현장용 호출 장치를 설치한 자리(5단계 S5F, 인계 임무 S8F)뿐이다. 호출 장치는 그 임무에서 보내 주고 현장에 설치하는 임무 아이템이라 잃어버려도 다시 놓인다. 들고 다녀야 하는 교신 물건은 두지 않는다. 게임에서는 짐이 되고, 잃어버리면 이야기가 끊기기 때문이다. 그래서 현장에서 2반의 목소리가 처음 들리는 때가 5단계 헬기 앞이 된다.
- **2반은 묻는 말에 답한다.** 피하는 것은 셋뿐이다. 약속(구조, 귀환, 데려가는 일에 대해 된다고도 안 된다고도 하지 않는다), 원인, 위치. 그 밖의 것(누가 무엇을 하는지, 왜 늦었는지, 저쪽 사정, 날씨)은 짧게 사실대로 답한다. 피하는 대답이 드물어야 피할 때 무게가 실린다.
- 정시 교신으로 여는 장면의 첫 인사는 대본에 적힌 단계가 아니라 재생될 때의 단계 인사를 쓴다 (LORE 6장). 임무 뒤 교신은 인사 없이 번호로 연다.
- 주인공은 원작 방송에서 들은 것과 손에 든 서류의 날짜를 말해도 된다. 2반은 방송 내용을 확인해 주지도 부정하지도 않는다. 그 줄을 놓쳐도 장면이 통해야 한다.
- 2반 쪽 말에는 말줄임표를 쓰지 않는다. 망설임은 침묵과 끊김으로 보인다. 주인공 쪽 망설임은 썼다 지우는 타이핑으로 보인다.
- 장면은 문장으로 해설하지 않는다. 브랜스컴이 무엇을 느꼈는지, 주인공이 무엇을 깨달았는지 쓰지 않는다.

## 2. 교신 장면의 화면

### 교신 탭

단말 창에 교신 탭을 둔다. 단말 장면은 모두 이 탭 안에서 재생되고, 끝난 장면과 짧은 교신(LORE 6장)은 이 탭에 기록으로 쌓인다. 2026-10-10에 없앤 무전 기록 탭은 잡음을 늘어놓은 화면이었다. 이 탭은 이야기 장면을 담는 자리라서 다시 둔다. 조립 단말에도 있다.

- 탭 위쪽은 기록 칸, 맨 아래 한 줄은 주인공의 입력 줄이다. 2반 줄은 기록 칸에 들어오고, 주인공 줄은 입력 줄에 타이핑된 뒤 송신하면 기록 칸으로 올라간다. 기록 칸의 줄 앞에는 호출부호가 붙는다.
- 기다리는 장면이나 짧은 교신이 있으면 단말 오브젝트에서 짧은 수신 잡음이 나고 불이 깜박인다. 이 소리는 플레이어에게만 들리고 좀비를 끌지 않는다. 단말 창의 교신 탭에는 임무 탭과 같은 호박색 점이 뜬다.
- 단말을 열 때 기다리는 장면이 있으면 창이 교신 탭으로 열리고 장면이 재생된다. 창이 열려 있는 동안 걸린 장면은 점만 띄우고, 탭을 누르면 재생된다. 3장 트리거의 '단말을 연다'는 이 둘을 다 뜻한다.
- 장면 도중 다른 탭을 누르면 건너뛴 것으로 친다.

### 두 목소리

| | 2반 (참나무) | 주인공 (0347) |
| --- | --- | --- |
| 자리 | 교신 탭 기록 칸 | 교신 탭 입력 줄. 송신하면 기록 칸 |
| 글자 | 무전 초록. 한 줄씩 신호가 잡히듯 들어온다 (확장 API 텍스트의 `signal` 등장) | 흰색 계열. 커서와 함께 한 글자씩 찍힌다 (확장 API 텍스트의 `type` 등장, 커서) |
| 속도 | 고르다. 무전 장면 속도 (초당 28자) | 사람이 치는 속도. 조금 느리고 고르지 않다 |
| 줄 앞 소리 | 짧은 수신 잡음 | 송신 키 딸깍 |

### 줄의 시간

- 한 줄이 다 찍히면 읽을 시간을 준 뒤 다음 줄을 시작한다. 읽을 시간은 글자 수에 비례하고 (가안 초당 12자, 최소 1.5초), 그 뒤에 반 박자(가안 0.5초)를 더 쉰다. 숫자는 게임에서 보고 고친다.
- `[신호 끊김 N초]`, `[침묵 N초]`, `[잡음 N초]`의 N초는 이 간격과 따로 더한다. 연출의 쉼이 읽는 시간에 묻히지 않게 하기 위해서다.

### 소리

- 교신 탭 장면 동안 게임 소리를 낮추고 (가안 절반) 낮은 무전 잡음을 깐다. 장면이 끝나면 되돌린다.
- 현장 교신은 게임 소리를 그대로 둔다. 헬기와 좀비 소리가 장면의 일부다.
- 소리는 구현 때 바닐라 무전 소리에서 고른다.

### 현장 교신 (S5F, S8F)

- 단말 창이 없으므로 화면에 직접 띄운다. 가안은 화면 위쪽 가장자리이고, 화면을 어둡게 하지 않는다. 헬기와 좀비가 화면 가운데에서 보여야 하기 때문이다. 자리와 모양은 구현 때 게임에서 다듬는다.
- 게임을 멈추지 않는다. 좀비가 가까이 오면 다음 줄을 미루고, 멀어지면 이어 간다.
- 끝나면 교신 탭에 기록으로 남는다.

### 혼잣말

- 주인공 머리 위에 뜬다. 대본에 적힌 이야기 혼잣말은 평소 혼잣말보다 오래 둔다 (가안 두 배).
- 이야기 혼잣말은 교신 탭에 '현장 기록'으로 함께 남는다. 놓쳐도 단말에서 다시 읽을 수 있다.

### 대본 기호

| 기호 | 뜻 |
| --- | --- |
| `참나무:` | 2반 줄. 기록 칸에 신호처럼 들어온다. 이관 뒤에는 `관리 7:`이다. |
| `0347:` | 주인공 줄. 입력 줄에 타이핑된다. |
| `(혼잣말)` | 교신 밖에서 주인공 머리 위에 뜨는 말 (헤일로). |
| `[신호 끊김 N초]` | 2반 쪽 글자가 지직거리며 흐려지고 N초 뒤 이어진다. |
| `[침묵 N초]` | 아무것도 뜨지 않는다. 잡음만 낮게 깔린다. |
| `[잡음 N초]` | 잡음 소리만 난다. 글자는 없다. |
| `[지움: 문구]` | 주인공이 문구를 치다가 지우고 다음 문구를 친다. |

### 멈춤, 건너뛰기, 기록

- 교신 탭 장면은 게임 시간을 멈추고 재생한다. 현장 교신은 멈추지 않는다.
- 건너뛰기 키는 따로 둔다. Esc는 게임 메뉴를 여는 키라 쓰지 않는다. 무심코 눌러 장면을 잃지 않게 하기 위해서다. 키는 구현 때 정한다.
- 장면이 끝나거나 건너뛰면 교신 탭에 기록으로 남는다. 기록에서 `[신호 끊김 N초]`와 `[침묵 N초]`는 `[송신 중단 N초]`가 되고, 지운 문구는 남지 않는다. 주인공 줄은 `0347:`로 남는다.
- 기록의 장면 머리에서 그 장면을 다시 재생할 수 있다. 다시 재생하면 처음과 같은 연출로 나온다.
- 기록은 장면 ID만 저장하고 글은 대본에서 읽는다.
- 장면이 시작될 때 이전 장면이 재생 중이면 그 장면이 끝난 뒤에 시작한다.

### 제목 카드

- S0이 끝나면 '도토리 작전' 제목 카드를 띄운다.
- 1~5단계에 들어선 뒤 처음 단말을 열 때, 창이 뜨기 전에 단계 이름 카드(접수, 분류, 대조, 지정, 전담)를 띄운다. 싸우는 중에 뜨지 않게 단말을 여는 때로 미룬다.
- 8단계는 S8 뒤 상자를 열 때 '이관' 카드를 띄운다 (4장 S8). 이름 없는 6·7단계와 9단계부터는 카드가 없다.
- 카드는 5초 머문다 (제목 시간 규칙).

**나오는 순서.**

- 트리거가 걸려도 '기다리는 장면'이 아직 나오지 않았으면 기다렸다가 그 다음에 나온다. 강화 혈청은 첫 보급 무렵부터 살 수 있어 S2가 S1보다 먼저 걸릴 수 있기 때문이다. S2는 보통 1단계 끝 무렵에 나온다.
- 단말 장면은 자기 단계(1~2는 2단계)가 끝날 때까지 트리거가 걸리지 않으면 버린다. 버린 장면은 아무도 기다리지 않는다. 강화 혈청을 끝내 사지 않은 사람에게는 S2와 S2B가 없고, S3은 S2B를 기다리지 않는다.
- 이야기 임무에 붙은 장면(S1F, S2F, S4F, S5F, S6F, S7F, S8F)은 단계와 상관없이 그 임무를 할 때 나오고 버리지 않는다. 다른 장면도 이 장면을 기다리지 않는다. 이야기 임무를 미룬 사람은 S6이 S5F보다 먼저 나올 수 있다. 이야기 임무는 단계에 들어서면 먼저 배정되므로 드문 경우로 보고 받아들인다.
- K1~K4는 단계마다 차례로 하나씩 나온다. 버린 K는 다시 나오지 않고 다음 단계에 다음 K가 나온다. 넷을 다 쓰면 더 나오지 않는다. 거래는 그대로 돈다.

## 4. 장면 대본

### S0 첫 교신

> 참나무: [잡음 2초] 여기는 참나무. 0347, 응답 바랍니다.
> 0347: 누구야. 구조대야?
> 참나무: 육군 시료 분석 파견대입니다. 구조대는 아닙니다.
> 0347: 근데 0347은 뭐야.
> 참나무: 책자 마지막 쪽에 적힌 번호입니다. 앞으로 그 번호로 부릅니다.
> 0347: 헬기 봤어. 그거 다시 와? 나 태우러?

## 5. 이야기 임무 현장

### 장소 고르기

- 그 단계 거리대 안에서 고른다. 맵 전체 건물 목록(`IsoMetaGrid.getBuildings`)을 쓴다. 불러지지 않은 칸의 건물도 위치, 크기, 방 이름이 있다.
- 건물을 고를 때는 방이 많은 비주거 건물(가게, 교회, 창고, 사무실)을 먼저, 없으면 가정집을 고른다. 빈터가 필요한 장면은 맵 구역(숲, 농지 같은 구역 종류)에서 막히지 않은 땅을 고른다.
- 아지트 건물과 이미 쓴 곳은 뺀다. 플레이어가 뒤진 기록(`OA_Searched`)이 있는 건물도 뺀다. 이미 털어 본 집에 경찰 초소가 차려져 있으면 어색하기 때문이다. 남는 건물이 없으면 빈터에 천막으로 세운다.
- 무대는 임무를 받을 때 정하고 임무에 저장한다. 그 칸이 처음 불러질 때 한 번 깔고, 중복은 modData로 막는다. 깔 자리가 막혔거나 이미 털린 칸이면 그 소품만 뺀다.
- 무대에는 바닐라 스프라이트, 아이템, 옷차림, 차량만 쓴다. 모드를 빼도 평범한 시체, 천막, 바리케이드로 남는다.
- 시체와 피는 깨끗하게 쓴다. 핏자국 데칼은 장소당 한두 장이다.

| 핏자국 | 전부 | `addBloodSplat`, `addTrailOfBlood` | 확인함 (jar) |
| 차량 배치, 문, 배터리, 연료 | 1, 2, 3, 4 | `addVehicleDebug`, `RandomizedWorldBase.addVehicle` | 확인함 (jar) |
| 위치 반복음과 멎는 조건 | 1, 2, 4, 7 | 바닐라 소리 | 미확인 |
| 트리거 | 전부 | 원 진입, 아이템 집기, 용기에 넣기, 판자 떼기, 시간 경과, 헬기 접근 | 일부 있음 (임무 원, 아이템) |
| 교신 탭 재생기와 기록 | 전부 | 단말 창 안에 그리기, 확장 API 텍스트 효과 (`signal`, `type`, 커서) | 텍스트 효과는 화면용으로 있음. 단말 창 안에서 쓸 수 있는지 미확인. 재생기와 기록은 새로 |
| 현장 교신 표시 | 5, 8 | 확장 API 텍스트 (화면 위쪽, 어둡게 하지 않음) | 텍스트 기능 있음 |
| 대기 알림 | 전부 | 단말 오브젝트의 수신 잡음(플레이어에게만)과 불 깜박임, 교신 탭 호박색 점 | 탭 점은 임무 탭에 있음, 나머지 미확인 |
| 장면 중 게임 소리 낮추기 | 전부 | 소리 볼륨 조절, 무전 잡음 깔기 | 미확인 |
| 제목 카드 | 시작, 1~5, 8 | 확장 API 제목 실험실(title-lab) 작업분 | 따로 진행 중 |
| 혼잣말 | 전부 | 지금 Say 모듈. 이야기 혼잣말은 두 배로 오래 두고 교신 탭에 남긴다 | 있음, 오래 두기와 기록은 새로 |

소품 타일 이름은 바닐라 타일 정의(newtiledefinitions.tiles)에서 확인했다. 간이침대 타일은 바닐라에 없어 들것과 침낭으로 대신한다. 옷차림 이름(Police, HospitalPatient, Nurse, Doctor, ArmyCamoGreen, HazardSuit 등)은 구현 때 바닐라 옷차림 정의에서 다시 확인한다.

## 7. 만드는 순서

1. 교신 탭과 재생기. 모든 단계의 중심이다.
2. 1단계 하나를 끝까지: S0, S1, S1F와 임시 경찰 초소 무대. 무대 부품은 이 단계에 필요한 것만 먼저 만든다.
3. 게임에서 감정이 실제로 오는지 본다. 그 판단으로 나머지 단계로 넓힌다.
4. 번역(영어판)은 맨 마지막에 한 번에 한다. 그 전까지 대본은 한국어만 쓴다 (2026-10-15 사용자 결정).
