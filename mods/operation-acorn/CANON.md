# 지켜야 할 기준

이야기, 연출, 문구를 제안하거나 평가할 때 쓰는 기준이다. 워크플로우의 평가자는 이 문서의 항목 번호를 들어 판정한다.

- **필수** 항목을 어긴 제안은 탈락이다. 아무리 재미있어도 고쳐 오기 전에는 받지 않는다.
- 이 문서의 항목은 사용자 결정으로만 바뀐다. 평가자가 항목이 틀렸다고 보면 탈락시키지 말고 '기준 이의'로 따로 적는다.
- 자세한 내용은 LORE.md(설정), SCENES.md(연출), DESIGN.md(시스템), NUMBERS.md(수치)에 있다. 이 문서는 어기면 안 되는 것만 모은다.
- 원작 사실은 게임 파일에서 확인한 것만 적는다. 확인하지 못한 것은 '미확인'으로 표시한다.

## 2. 게임 시스템 (S)

이야기는 게임이 실제로 보여 주는 것과 반대로 가면 안 된다. 플레이어는 문장보다 수치를 먼저 겪는다.

| # | 기준 |
| --- | --- |
| S1 | **NPC가 없다.** B42에는 사람 NPC가 없다. 살아 있는 사람을 만나는 장면, 대화하는 사람, 따라오는 사람을 쓰지 않는다. 2반은 교신, 문서, 헬기, 보급 상자로만 나온다. |
| S2 | **시작 지점은 세이브마다 다르고 맵은 넓다.** 지명이나 특정 건물에 기대는 장소를 쓰지 않는다. 이야기 장소는 그 단계 거리대 안의 건물이나 빈터에 차린 임시 시설이다. 맵 끝에서 시작한 사람도 갈 수 있어야 한다. |
| S3 | **거래 흐름.** 납품 상자를 빈터에 두고 밀봉한다 → 단말로 헬기를 부른다 → 헬기는 착륙하지 않고 밀봉 상자를 걸어 올린 뒤 보급 상자와 빈 납품 상자를 내려놓는다. 헬기가 내려앉는 장면, 사람이 타고 내리는 장면은 쓰지 않는다. |
| S4 | **운항은 단계가 오를수록 좋아진다.** 호출 간격은 3일에서 1일로, 상자는 50에서 350으로 커지고 9단계부터 끝없이 커진다. 도착이 빨라지고 밤에도 온다. 이야기는 이것을 '형편이 나아짐'으로 그리지 않는다 (L9). |
| S5 | **상점.** 값은 고정이고 재고는 떨어지지 않는다. 쓸 때마다 값이 오르는 것은 강화 혈청뿐이다. 확장 키트는 붙이는 수에 상한이 없다 (의도). 치료 혈청은 5단계부터 팔고, 지연제, 역전제, 검사 키트는 1단계부터 판다. 혈청 칸에는 구매 한도가 없다. 상점에서 산 물건은 납품을 받지 않는다. |
| S6 | **거래 수치는 이야기 때문에 바꾸지 않는다.** 시세, 반복 감소, 새 지역 웃돈은 설정으로 설명할 뿐이다. 이야기가 바꾸는 것은 비고, 표식, 요청 문구의 결뿐이다. |
| S7 | **단계.** 신뢰도는 1~5단계(접수, 분류, 대조, 지정, 전담), 6·7·8단계(8 = 이관), 9단계부터 끝없이 이어진다. 단계마다 주 이야기 임무가 하나다. 임무는 한 번에 하나다. |
| S8 | **이야기는 진행을 막지 않는다.** 이야기 임무를 놓치면 일반 임무 하나 뒤에 다시 제안된다. 문서를 읽지 않아도, 장면을 건너뛰어도 진행이 막히지 않는다. 임무 물품이 없어져도 이어진다. |
| S9 | **결말은 게임을 멈추지 않는다.** 결말은 8단계 '이관'이다. 이관 뒤에도 거래, 수치, 헬기, 임무가 그대로 이어진다. |
| S10 | **선택지가 없다.** 주인공 대사는 고정 대본이다. 결말은 갈리지 않는다. |
| S11 | **교신 장면의 형식.** 2반 줄은 화면 가운데 왼쪽에 무전 초록 글자로, 주인공 줄은 화면 아래에 커서와 함께 타이핑된다. 장면 하나는 6~12줄이고 키 하나로 건너뛴다. 끝나면 교신 사본으로 남는다. 교신은 일정이 아니라 사건에 붙는다. |
| S12 | **월드 연출은 바닐라 에셋만 쓴다.** 바닐라 타일, 아이템, 옷차림, 차량만 쓴다. 모드를 빼도 평범한 시체, 천막, 바리케이드로 남아야 한다. 무대는 그 칸이 처음 불러질 때 한 번 깐다. 쓸 수 있는 부품과 확인 상태는 SCENES.md 6장에 있다. |
| S13 | **헬기 '없음'과 늦은 설치.** 바닐라 헬기 설정이 '없음'이거나 모드를 늦게 넣은 세계에서도 이야기가 성립해야 한다. 첫 상자는 조용히 놓이고 첫 무전은 늦은 보급용을 쓴다. |
| S14 | **샌드박스가 수치를 바꾼다.** 유효 기간, 호출 간격, 기한 같은 규칙 수치를 세계관 문장에 쓰지 않는다. 수치는 UI에 둔다. |
| S15 | **확장 API에는 내용이 없다.** 연출 부품은 내용 없는 일반 부품으로 API에 두고, 무대와 대본은 OA의 데이터다. |
| S16 | **매 틱, 전체 스캔으로 도는 연출을 만들지 않는다.** 트리거는 이벤트(원 진입, 아이템 집기, 용기에 넣기, 시간 경과, 헬기 접근)로 건다. |
| S17 | **멀티는 테스트하지 않지만 막지도 않는다.** 멀티를 막는 설정이나 문구를 넣지 않는다. |
| S18 | **대상은 고인물이다.** 수백 일을 이어 가는 플레이어다. 한 번 보고 끝나는 연출보다 오래 남는 것, 맵을 어지르지 않는 것을 고른다. |

## 3. 확정된 이야기 결정 (L)

| # | 기준 |
| --- | --- |
| L1 | **주제.** 구해 줄 줄 알았던 무전 너머가, 사실은 갇힌 나에게 기대 살고 있었다. 탈출을 꿈꾸던 사람이 여기서 버티는 사람이 된다. 모든 장면은 이 주제와 LORE 0장의 단계별 감정선 중 하나를 맡아야 한다. 맡는 감정이 없는 장치는 넣지 않는다. |
| L2 | **주인공이 가고 싶은 곳은 무전 너머(2반 쪽)다.** 막연한 바깥이 아니다. 바깥이 망한 것은 방송으로 이미 안다 (V7). 5단계의 꺾임은 '그 목소리 쪽도 안전하지 않다'다. |
| L3 | **주인공이 따르는 이유는 셋이다.** 혼자서는 못 나간다, 혈청, 혼자 품는 희망. 희망의 근거는 '배정 대상 등재'를 명단으로 잘못 읽은 것이다. 2반은 희망을 주지도 꺾지도 않는다. |
| L4 | **2반은 구조, 철수, 귀환을 약속하지 않는다.** 그런 문장은 어떤 문서와 대사에도 없다. |
| L5 | **봉쇄선은 한쪽으로만 열린다.** 7/15에 첫 선이 무너지고 더 바깥에 새 선이 그어졌다. 그 뒤 구역에 들어온 사람은 누구든 나가지 못한다. 2반은 5단계 전에는 이 규칙을 말하지 않는다. 선은 풀라는 명령이 오지 않아 남아 있다. |
| L6 | **잔류물은 배정 혈청의 원료다.** 왜 듣는지는 끝까지 모른다. 바깥에도 감염이 번져 시료값은 떨어지지 않고 요청은 급해진다. |
| L7 | **운항이 좋아지는 것은 응답이 끊긴 채집점의 노선이 정리되기 때문이다.** 이관 뒤에는 관리 7이 노선을 합친다. 문서는 이 연결을 문장으로 쓰지 않는다. |
| L8 | **키트와 소모품은 해체된 부대에서 나온다.** 재고가 떨어지지 않는 것은 해체되는 부대가 끊이지 않기 때문이다. 키슬링 비고가 출처를 적는다. |
| L9 | **원인을 확정하지 않는다.** 낙하설, 누출설, 두 사건설이 필수 단서를 비슷한 수로 나눠 받는다. 단서를 더하거나 빼면 LORE 2장의 균형을 다시 센다. 외계 기원은 낙하설의 한 가지 읽기로만 남고 어떤 문서도 확정하지 않는다. |
| L10 | **2반의 위치는 끝까지 밝히지 않는다.** 날씨, 시차처럼 거리를 짐작할 말도 쓰지 않는다. |
| L11 | **인물.** 오드웨이(서명뿐, 4단계부터 대리), 브랜스컴(교신, 인사가 단계마다 깎임, 반말은 5단계와 8단계 두 번뿐이고 곧바로 정정), 키슬링(명세서, 덤은 실무 물품), 더니건(생각을 적는 유일한 사람), 애시다운(관찰 기록체, 화씨). 사람이 바뀌는 일은 오드웨이의 대리 서명 한 번뿐이다. 주인공은 개인사가 없고 반말 구어로 짧게 말한다. |
| L12 | **결말은 B '이관'이다.** 브랜스컴의 작별, 마지막 투하분(휴대 무전기), 상태표, 관리 7. |
| L13 | **날짜는 서류에만 쓴다.** 무전과 명세서 비고에는 달력 날짜가 없다. 서류의 날짜는 원작 연표 기준이다. |
| L14 | **임무 장소는 임시 시설이다.** 1 임시 경찰 초소, 2 임시 진료소(연휴 발열 때 연 곳), 3 두 집(택 1), 4 7/15에 버려진 야전 캠프, 5 임시 주민 접수소, 6 임시 격리 병동, 7 임시 수용 시설, 8 인계 임무. |
| L15 | **이야기 장치는 감정이 큰 순간에만 쓴다.** 단계마다 교신 장면 한두 개와 현장 하나다. 그 사이는 생존 플레이로 남는다. |

## 5. 글 (W)

| # | 기준 |
| --- | --- |
| W1 | 한국어는 사람이 쓴 문장처럼 쓴다. 번역투, LLM투를 쓰지 않는다. |
| W2 | 게임 안 문장에는 정확한 개수, 다른 규칙과 엮인 설명, 같은 말의 반복, 단서 달기를 쓰지 않는다. 효과 수치는 툴팁에 둔다. |
| W3 | 무전은 '-ㅂ니다'와 명사형, 명세서는 개조식(-함, -것, -바람), 애시다운은 관찰 기록체, 주인공은 반말 구어다. |
| W4 | 기록 서식에는 말줄임표를 쓰지 않는다. 침묵은 `[송신 중단 N초]`, 고친 자리는 `[줄 그음: …]`, 먹칠은 한 곳뿐이다. |
| W5 | 용어: '물 저장소'(물탱크 금지), '정산 잔액'(크레딧은 UI만), '채집점', '기준일', '이관'(결말만, 다른 곳은 '인계'), '배정 혈청'(UI 이름은 '치료 혈청'). |
| W6 | 1993년에 없는 매체와 말을 쓰지 않는다. 팩스, 타자기, 사본 번호, 무선 절차어까지다. 미국 사람은 체온을 화씨로 말한다. 의료 차트는 화씨, 실험 보관 온도는 섭씨다. |
| W7 | 어떤 문서도 해설로 끝내지 않는다. 장면은 인물이 무엇을 느꼈는지 문장으로 설명하지 않는다. |
| W8 | 미국 기관 문서에는 '신고', '설비', '카운티 보건 담당'을 쓴다. |

## 6. 평가 질문

평가자는 제안마다 아래를 차례로 묻고, 걸리면 항목 번호를 적는다.

1. 원작 연표나 원작 사실과 어긋나는가? (V)
2. 게임이 실제로 보여 주는 것(운항 개선, 떨어지지 않는 재고, 무한 확장, 단계 해금 시점)과 반대로 말하는가? (S4, S5, S7)
3. 어디서 시작해도 성립하는가? 헬기 '없음', 늦은 설치, 모드 제거에서 깨지는가? (S2, S12, S13)
4. 이야기를 건너뛴 사람의 진행을 막는가? (S8)
5. 살아 있는 사람이 나오는가? (S1)
6. 2반이 무언가를 약속하는가? 원인을 확정하거나 가설 균형을 깨는가? (L4, L9)
7. 그 장면이 맡는 감정이 LORE 0장의 어느 단계인가? 없으면 탈락이다. (L1, L15)
8. 반려한 방향을 되살리는가? (X)
9. 글이 W 규칙을 어기는가?
10. 필요한 월드 연출 부품이 SCENES.md 6장에서 '확인함'인가? 미확인이면 확인할 것으로 적는다.
