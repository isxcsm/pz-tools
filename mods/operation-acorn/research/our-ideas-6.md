# 우리 아이디어 6차 (브레인스토밍 마지막)

## 수색

| 후보 | 효과 | 자리 |
| --- | --- | --- |
| 소음 계기 | 내가 지금 내는 소리의 반경을 발밑에 원으로 보여 준다. 조용한 손·웅크려 걷기의 효과가 눈에 보인다 | 하위 |
| 넓은 시야 | 시야 원뿔이 조금 넓어진다 | 중위 |
| 빠른 뒤돌기 | 뒤돌아보는 속도가 빨라진다 | 하위 |
| 살짝 열기 | 문을 반만 열어 안을 엿본다. 소리가 거의 없다 | 하위 |
| 어둠 속 발걸음 | 어두운 실내에서 물건에 걸려 넘어지거나 소리를 내는 일이 준다 | 중위 |
| 불 끈 채 이동 | 집 안 불을 켜지 않아도 가구 윤곽이 보인다 | 중위 |
| 시료 채취 손 | 좀비 시체에서 시료를 채취하는 속도가 빨라진다 | 하위 |

## 운반

| 후보 | 효과 | 자리 |
| --- | --- | --- |
| 진흙과 눈 | 눈이나 비 온 뒤 땅에서 짐을 지고 걸을 때 느려짐이 준다 | 중위 |
| 차 안 짐 정리 | 차 안 좌석과 트렁크 사이로 옮기는 속도가 빨라진다 | 하위 |
| 동물 끌기 | 끈으로 동물을 끌고 갈 때 덜 버틴다 | 중위 |

## 생존

| 후보 | 효과 | 자리 |
| --- | --- | --- |
| 약물 대사 | 진통제, 항우울제, 수면제 같은 약의 효과가 오래 간다 | 중위 |
| 약초 효과 | 약초로 만든 약의 효과가 커진다 | 중위 |
| 씻기 | 몸과 옷을 씻는 속도가 빨라지고 물을 덜 쓴다 | 하위 |
| 피 묻은 몸 | 피투성이일 때 오르는 스트레스와 우울이 준다 | 하위 |
| 차 안 잠 | 차 안에서 자도 잠을 잘 잔다 | 하위 |
| 운전 피로 | 오래 운전해도 피로가 덜 쌓인다 | 중위 |
| 사고 탈출 | 차가 뒤집히거나 부서졌을 때 빨리 빠져나온다 | 중위 |
| 동물 길들이기 | 가축이 더 빨리 나를 따른다 | 중위 |

## 2차 연구판·캡스톤 이상 반응

| 후보 | 이름 예 | 효과 |
| --- | --- | --- |
| 혈청 환각 | 투여 후 이상 지각 | 강화 혈청을 맞을 때 몇 초간 이상한 장면(밤하늘, 불빛)이 스친다. 단계가 오를수록 선명해진다 (연출, 떡밥) |
| 무리의 꿈 | 수면 중 공유 이미지 (분류 보류) | 자고 나면 무리가 몰려가는 방향이 꿈으로 보인다 |
| 정적 | 청각 이상 과민 (분류 보류) | 주변이 조용할수록 감각 강화가 커지고, 큰 소리에는 잠깐 멍해진다 (약점이 붙은 2차 노드) |
