# PZ Tools

**คุณดูแลการเอาชีวิตรอด ส่วน PZ Tools เก็บจุดที่ย้อนกลับไปได้** เครื่องมือสำรองข้อมูลอัตโนมัติ ดูประวัติเซฟ และฟื้นฟูตัวละครสำหรับ Project Zomboid

## ความสามารถ

- ตรวจจับเซฟที่กำลังเล่น ค่าเริ่มต้นคือสำรองทุก **5 นาที** และเก็บ **ข้อมูลสำรองอัตโนมัติ 20 ชุด**
- เปลี่ยนชื่อข้อมูลสำรองแบบสั่งเองได้ และไม่ลบตามจำนวนจำกัดของข้อมูลสำรองอัตโนมัติ
- เลือกเรียก `save(true)` ผ่าน JVM agent ก่อนสำรอง พร้อมนับถอยหลัง 5 วินาทีในเกมได้ โดยไม่ต้องติดตั้งม็อด Workshop
- แสดงภาพย่อ ชื่อตัวละคร เวลาเอาชีวิตรอด และสถานะการตาย
- ติดตามการเปลี่ยนแปลงด้วย USN สำรองแบบเพิ่มเฉพาะส่วนที่เปลี่ยน บีบอัด และเลือกตัดข้อมูลซ้ำได้ หากใช้ USN ไม่ได้จะสแกนทั้งหมด โดยเปิดการเปรียบเทียบแฮชเป็นค่าเริ่มต้น
- ตรวจสอบ นำเข้า และส่งออก ZIP พร้อมแสดงความคืบหน้าและบันทึกการทำงาน
- รักษาและชุบชีวิตขณะไม่ได้เล่น โดยคงลักษณะนิสัยทั้งเชิงบวกและเชิงลบ ทักษะ และค่าประสบการณ์ไว้

## เริ่มใช้งาน

ต้องใช้ **Windows x64 และ .NET 10 runtime** เปิด `PzTools.App.exe` แล้วตรวจสอบโฟลเดอร์เซฟและข้อมูลสำรอง สั่งสำรองเองหรือเล่นโดยเปิดสำรองอัตโนมัติ ตั้งช่วงเวลาเป็น `0` เพื่อปิดการสำรองอัตโนมัติ ต้องออกจากเซฟนั้นก่อนกู้คืนข้อมูลหรือฟื้นฟูตัวละคร

## ข้อจำกัด

การฟื้นฟูแก้ไขเฉพาะเซฟปัจจุบัน ไม่แก้ไขข้อมูลสำรองเก่า รองรับ **Build 42.20.4 รูปแบบโลก 249 และผู้เล่นในเครื่องคนเดียว (ID 1)** การกู้ไอเท็มต้องพบข้อมูลซอมบี้ของตัวเองที่ตรงกันเพียงรายการเดียว โดยตรวจตำแหน่งที่บันทึกไว้และชื่อในบัตรประจำตัว ไม่รองรับซอมบี้ที่ย้ายตำแหน่ง เป้าหมายที่ไม่มีบัตร หรือศพในชังก์แผนที่ ไม่ลบลักษณะนิสัยเชิงลบ และไม่รับประกันว่าจะล้างผลกระทบเฉพาะของม็อดได้ทั้งหมด

สะพานเชื่อมการบันทึกเป็นฟังก์ชันทดลองสำหรับผู้เล่นคนเดียวบน Build 42 / Java 25 และปิดได้ในตั้งค่า ข้อความบันทึกเสร็จในเกมไม่ได้หมายถึงสำรองเสร็จ และไม่ได้รับประกันว่าข้อมูลทั้งโลกมาจากจังหวะเดียวกัน

ข้อมูลสำรองแบบสั่งเองยังถูกลบได้จากคำสั่งลบโดยตรง หรือการล้างข้อมูลสำรองที่ไม่มีเซฟต้นทางเมื่อเซฟนั้นหายไป ควรส่งออกชุดสำคัญไปเก็บในอุปกรณ์อื่น
