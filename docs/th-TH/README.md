# PZ Tools

PZ Tools เป็นแอป Windows ที่ไม่เป็นทางการสำหรับสำรองและกู้คืนเซฟของ Project Zomboid รวมถึงฟื้นฟูตัวละครในรูปแบบเซฟที่รองรับ ไม่ใช่ผลิตภัณฑ์ของ The Indie Stone

<a id="features"></a>
## ความสามารถ

สำรองด้วยตนเองหรือตามเวลา ตั้งชื่อรายการสำรอง ดูภาพย่อและข้อมูลตัวละคร นำเข้าและส่งออก ZIP รวมถึงรักษาหรือชุบชีวิตขณะไม่ได้เล่นเซฟนั้น หน้าจอ ชื่อเริ่มต้นของข้อมูลสำรองใหม่ และการแจ้งเตือนบันทึกเกมรองรับ18ภาษา มีธีม โหมดถาดระบบที่เลือกเปิดได้ ตัวแสดงความคืบหน้า และตัวกรองบันทึกการทำงาน

<a id="getting-started"></a>
## ติดตั้งและเปิดใช้งาน

ต้องใช้ **Windows x64** และ **[.NET 10 runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)** สำหรับ Windows x64 ปัจจุบันแอปขอสิทธิ์ผู้ดูแลระบบเพื่อติดตามการเปลี่ยนแปลงไฟล์ด้วย USN แพ็กเกจที่เผยแพร่มีส่วนประกอบ WinUI และ Java runtime ขนาดเล็กสำหรับเชื่อมต่อเกม แต่ไม่มีไฟล์ JAR ของเกม

ดูแพ็กเกจพร้อมใช้งานที่ [Releases](https://github.com/isxcsm/pz-tools/releases) หากยังไม่มีแพ็กเกจ ให้ใช้ขั้นตอนบิลด์ด้านล่าง **Source code ZIP ของ GitHub ไม่ใช่แอปที่เปิดใช้งานได้ทันที**

1. แตกแพ็กเกจ **ทั้งหมด** ลงในโฟลเดอร์เดียว แล้วเปิด `PzTools.App.exe` อย่าย้ายเฉพาะ EXE หรือปนไฟล์จากคนละบิลด์
2. ตรวจสอบโฟลเดอร์เซฟในตั้งค่า และเลือกโฟลเดอร์สำรองแยกต่างหาก อย่าใช้โฟลเดอร์เซฟของเกมเป็นปลายทางสำรอง
3. เลือกเซฟ สั่งสำรองเอง และตรวจสอบว่าแอปแจ้งเสร็จสมบูรณ์ ตั้งช่วงเวลาและจำนวนข้อมูลสำรองอัตโนมัติที่จะเก็บ
4. ก่อนอัปเดต ให้ปิด PZ Tools และเตรียมแพ็กเกจใหม่ทั้งชุดในอีกโฟลเดอร์ เก็บเซฟและข้อมูลสำรองแยกจากไฟล์แอป

การตั้งค่าและข้อมูลจัดการอยู่ที่ `%LOCALAPPDATA%\PzTools` ส่วนข้อมูลสำรองอยู่ในโฟลเดอร์ที่เลือก ดู [ตำแหน่งไฟล์และข้อมูล (ภาษาเกาหลี)](../deployment-layout.md)

<a id="backups-and-retention"></a>
## การเก็บและลบข้อมูลสำรอง

ค่าเริ่มต้นคือ **ทุก5นาที และเก็บข้อมูลสำรองอัตโนมัติ20ชุด** ช่วงเวลา `0` ปิดการสำรองอัตโนมัติ การสำรองจะติดตามเซฟที่กำลังเล่น และเริ่มนับช่วงเวลาใหม่เมื่อเปิดแอปใหม่ โดยคงการตั้งค่าเดิมไว้

ข้อมูลสำรองแบบสั่งเองเปลี่ยนชื่อได้และไม่ถูกนับในขีดจำกัดของการสำรองอัตโนมัติ แต่ **ไม่ได้เก็บไว้ถาวร** การสั่งลบโดยตรงหรือการล้างข้อมูลหลังเซฟต้นทางหายไปอาจลบชุดที่สั่งเองด้วย ก่อนลบหรือย้ายเซฟต้นทาง ให้ส่งออกชุดสำคัญเป็น ZIP ไปยังไดรฟ์อื่น

การลบเฉพาะข้อมูลสำรองไม่ลบเซฟปัจจุบัน แต่จะกู้คืนหรือส่งออกชุดนั้นไม่ได้อีก การลบเซฟผ่านแอปจะลบข้อมูลสำรองของเซฟนั้นด้วย การคืนพื้นที่อาจเกิดภายหลัง จึงไม่ได้ทำให้ขนาดไฟล์ลดทันทีเสมอไป ดู [การตั้งค่า (ภาษาเกาหลี)](../configuration.md) และ [นโยบายการล้างข้อมูล (ภาษาอังกฤษ)](../repository-housekeeping.md)

<a id="game-saving"></a>
## บันทึกเกมก่อนสำรอง

การเชื่อมต่อที่เลือกเปิดได้จะขอให้เกมที่กำลังเล่นบันทึกก่อนคัดลอกไฟล์ โดยโหลด JVM agent และเรียก `GameWindow.save(true)` บนเธรดเกม ไม่ต้องใช้ม็อด Workshop หรือแก้ไขไฟล์ติดตั้งเกม เป็นฟังก์ชันทดลองสำหรับโครงสร้างที่ตรวจสอบของ **Build 42 / Java 25 แบบผู้เล่นคนเดียว** ไม่รองรับผู้เล่นหลายคน

การบันทึกกับการนับถอยหลัง5วินาทีมีสวิตช์แยกกัน **“บันทึกเกมสำเร็จ” ไม่ได้หมายถึง “สำรองเสร็จ”** เพราะยังต้องรวบรวมและบีบอัดไฟล์ต่อ หากปิดการเชื่อมต่อหรือเป็นเซฟที่ไม่ได้เล่น จะสำรองเฉพาะข้อมูลที่เขียนลงดิสก์แล้ว คำขอที่ล้มเหลวหรือผลไม่แน่ชัดจะไม่ถูกแจ้งว่าสำเร็จ ดู [การเชื่อมต่อบันทึกเกม (ภาษาอังกฤษ)](../save-bridge.md)

<a id="restore-and-archives"></a>
## กู้คืนและใช้ไฟล์ ZIP

ออกจากเซฟที่เลือกก่อนกู้คืน เลือกชุดสำรองและตรวจสอบหน้าต่างยืนยันให้ถูกต้อง **การกู้คืนแทนที่ไฟล์ปัจจุบัน ทำให้ความคืบหน้าหลังชุดสำรองนั้นหายไป** หากถูกขัดจังหวะ ให้เปิด PZ Tools อีกครั้งและตรวจสอบสถานะก่อนโหลดเซฟในเกม อย่าสันนิษฐานว่าการย้อนกลับอัตโนมัติสำเร็จแล้ว

ส่งออกเซฟปัจจุบันหรือข้อมูลสำรองเป็น ZIP และตรวจสอบ ZIP ก่อนนำเข้าได้ ควรเก็บ ZIP ระยะยาวไว้นอกโฟลเดอร์สำรองของแอป ชุดสำรองบนไดรฟ์เดียวกันไม่ป้องกันไดรฟ์เสีย ดูคำสั่งที่ทำงานแบบเดียวกันใน [คู่มือ CLI (ภาษาเกาหลี)](../cli.md)

<a id="character-recovery"></a>
## ฟื้นฟูตัวละคร

สร้างข้อมูลสำรองแบบสั่งเองหรือส่งออก ZIP ก่อน เพราะ **การฟื้นฟูตัวละครไม่ได้สร้างสำเนาไฟล์ต้นฉบับเพิ่ม** ฟังก์ชันนี้แก้ไขเฉพาะเซฟปัจจุบันที่ไม่ได้เล่น ไม่แก้ไขข้อมูลสำรองเก่า รองรับ **Build 42.20.4 รูปแบบโลก249 และผู้เล่นในเครื่อง1คน (ID 1)**

การรักษาหรือชุบชีวิตคืนค่าสุขภาพและล้างอาการบาดเจ็บหรือสถานะชั่วคราวที่รองรับ โดยคงลักษณะนิสัยทั้งบวกและลบ ประสบการณ์ ทักษะ สูตร และไอเท็มเดิมไว้ ไม่ได้ให้ภูมิคุ้มกันถาวรหรือแก้ผลกระทบจากม็อดทุกชนิด

ถ้าช่องเก็บของตัวละครที่ตายว่างอยู่ จะกู้ไอเท็มได้จากข้อมูลซอมบี้ของตัวเองที่ตรงกันเพียงรายการเดียว โดยอ้างอิงตำแหน่งที่บันทึกและชื่อในบัตรประจำตัว ไม่รองรับซอมบี้ที่ย้ายตำแหน่ง เป้าหมายไม่มีบัตร หรือศพในชังก์แผนที่ อาจต้องจัดอุปกรณ์ในมือใหม่ ดู [การฟื้นฟูและข้อจำกัด (ภาษาอังกฤษ)](../character-recovery.md)

<a id="compatibility-and-limits"></a>
## การจัดเก็บและความเข้ากันได้

ระบบเก็บส่วนที่เปลี่ยนแทนการทำสำเนาทั้งเซฟทุกครั้ง ใช้ NTFS USN เมื่อทำได้ มิฉะนั้นจะสแกนทั้งหมดและเปรียบเทียบเนื้อหา การตรวจสำเนาและบีบอัด Brotli เปิดเป็นค่าเริ่มต้น ส่วนการตัดข้อมูลซ้ำเป็นตัวเลือก ผลตอบกลับการบันทึกและการตรวจแต่ละไฟล์ **ไม่รับประกันว่าทุกไฟล์เป็นข้อมูลจากเวลาเดียวกันพอดี**

โครงการยังอยู่ระหว่างพัฒนาก่อนเผยแพร่ คลังสำรองที่รูปแบบไม่เข้ากันจะถูกปฏิเสธด้วย `repository-reset-required` ไม่มีการแปลงหรือลบอัตโนมัติ ให้เลือก **โฟลเดอร์สำรองใหม่ที่ว่าง** และเก็บโฟลเดอร์เก่าไว้หากยังต้องใช้ **อย่าลบ `Zomboid/Saves` หรือลบเฉพาะ `repository.db` เพื่อแก้ข้อผิดพลาดนี้** ดู [รูปแบบคลังข้อมูล (ภาษาเกาหลี)](../repository-format.md) และ [การตั้งค่าขั้นสูง (ภาษาอังกฤษ)](../runtime-configuration.md)

<a id="troubleshooting"></a>
## แก้ปัญหาและแจ้งข้อผิดพลาด

หากแอปไม่เปิด ให้ตรวจ runtime และความครบถ้วนของแพ็กเกจ หากไฟล์ถูกใช้งานหรือเปลี่ยนตลอด ให้รอเกมบันทึกเสร็จก่อนสำรองอีกครั้ง หากไม่สำรองอัตโนมัติ ให้ตรวจช่วงเวลา เซฟที่กำลังเล่น และ PZ Tools ยังทำงานอยู่หรือไม่ การปิดไปที่ถาดระบบไม่ใช่การออกจากแอป

เมื่อทำงานล้มเหลวหรือเสร็จเพียงบางส่วน ให้อ่านบันทึกก่อนสั่งซ้ำ การกู้คืนหรือแก้ไขตัวละครที่หยุดกลางทางต้องตรวจสอบก่อนโหลดเซฟอีกครั้ง เมื่อตั้ง [issue](https://github.com/isxcsm/pz-tools/issues) ให้ระบุเวอร์ชันหรือ commit ของแอป เวอร์ชันเกม ขั้นตอน และบันทึกที่เกี่ยวข้อง ลบเส้นทางส่วนตัวและข้อมูลลับออก ไม่แนบทั้งเซฟโดยไม่จำเป็น

<a id="building"></a>
## บิลด์จากซอร์ส

ต้องใช้ Windows, .NET SDK ตาม `global.json`, PowerShell 7, Windows x64 Java 25 JDK และเครื่องมือ C++/WinUI ของ Visual Studio รันจากโฟลเดอร์รากของคลังซอร์ส และเปลี่ยนเส้นทาง JDK ตัวอย่าง:

```powershell
$jdk = 'C:\path\to\jdk-25'
dotnet build PzTools.sln -c Release -p:Platform=x64 -p:JdkPath="$jdk"
dotnet test tests/PzTools.Backup.Tests -c Release -p:JdkPath="$jdk"
pwsh scripts/publish-app.ps1 -JdkPath $jdk -Output artifacts/app-local
```

สคริปต์เตรียมแอปและโปรแกรมทำงานร่วมกันใน **โฟลเดอร์ปลายทางใหม่หรือว่าง** ใช้อีกเส้นทางเมื่อเผยแพร่อีกครั้ง [คู่มือพัฒนาและตรวจสอบ (ภาษาอังกฤษ)](../development.md) อธิบายส่วนประกอบที่ต้องใช้ การทดสอบแพ็กเกจ CLI และการทดสอบที่ต้องเลือกเปิดเอง
