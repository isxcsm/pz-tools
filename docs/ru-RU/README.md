# PZ Tools

**Вы выживаете — PZ Tools сохраняет возможность вернуться.** Резервное копирование, история сохранений и восстановление персонажа в Project Zomboid.

## Возможности

- Определение активного сохранения; по умолчанию копия каждые **5 минут**, хранение **20 автоматических копий**.
- Ручные копии можно переименовывать; лимит автоматических копий их не удаляет.
- Необязательный вызов `save(true)` через JVM-агент перед копированием и отсчёт 5 секунд в игре, без мода Workshop.
- Миниатюры, имя персонажа, время выживания и отметка о смерти.
- Инкрементальное копирование через USN, сжатие, необязательная дедупликация; при недоступном USN — полное сканирование с проверкой хешей по умолчанию.
- Проверка, импорт и экспорт ZIP, индикаторы выполнения и журналы.
- Лечение и воскрешение вне игры с сохранением положительных и отрицательных черт, навыков и опыта.

## Начало работы

Нужны **Windows x64 и среда выполнения .NET 10**. Запустите `PzTools.App.exe`, проверьте папки сохранений и копий. Создайте ручную копию или играйте с автоматическим копированием. Интервал `0` отключает его. Перед восстановлением копии или персонажа выйдите из этого сохранения.

## Ограничения

Восстановление персонажа поддерживает только **Build 42.20.4, формат мира 249, одного локального игрока (ID 1)** и меняет текущее сохранение, а не историю. Возврат вещей возможен из единственной подходящей записи собственного зомби по сохранённой позиции и имени в удостоверении личности. Переместившиеся зомби, цели без удостоверения и тела в чанках карты не поддерживаются. Отрицательные черты сохраняются; снятие всех эффектов модов не гарантируется.

Мост сохранения — экспериментальная функция для одиночной игры Build 42 / Java 25; её можно отключить. Сообщение об успешном сохранении в игре означает возврат вызова, а не завершение резервной копии. Атомарный снимок всего мира не гарантируется.

Ручные копии всё же удаляются по явной команде или при очистке осиротевших копий после исчезновения исходного сохранения. Важные копии экспортируйте на другой носитель.
