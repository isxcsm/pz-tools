# Move a save to another PC

Export a save to a ZIP file on one PC and import it on the other. This also works for handing
a save to a friend.

## 1. Export

On the first PC, open **Save manager** and select the save. Select **Current save** to take
the save as it is now, or a backup to take that one. Press **Export ZIP** and choose where to
save the file.

To export the current save, quit to the main menu or close the game first. A backup can be
exported while you play.

The ZIP holds that one save or backup. The save's other backups don't go with it.

## 2. Import

On the other PC, open **Save manager** and press **Import archive**. Choose the ZIP. PZ Tools
shows what's in it: the save, the character, their survival time and when it was last played.
Press **Import**.

[Screenshot: The Import this save? dialog with the save's picture and details]

The save goes into your save folder and shows up in the list. It has no backups yet, and the
next automatic backup starts its history.

An import never replaces a save. If you already have one with the same name, the imported one
gets a number added, like `Survival(1)`.

## If it doesn't work

| Message | What to do |
| --- | --- |
| **Cannot export while playing. Quit the game.** | Quit to the main menu or close the game |
| **The save changed while exporting. Quit the game and try again.** | Quit to the main menu or close the game |
| **This file cannot be imported. Check that PZ Tools exported it.** | Only ZIPs exported by PZ Tools can be imported. A save zipped by hand can't |
| **Not enough disk space.** | Free up space on the drive with your save folder |
